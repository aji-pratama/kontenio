# TECH_PRD.md: Automated Vertical Video Factory

## 1. Executive Summary
**Goal:** Build a "Zero-Touch" video automation pipeline that transforms raw talking-head footage into high-retention vertical videos (9:16).
**Core Philosophy:** Execution-First. The system acts as a "content factory," orchestrated by a single Django command.
**Output Style:** Split-screen layout with automated contextual visuals (Top) and the speaker (Bottom), bridged by a glassmorphism transcription overlay.

---

## 2. Technology Stack

### Backend (The Orchestrator)
* **Framework:** Django 5.x (Lean Setup - Single App).
* **Interface:** Django Management Command (CLI).
* **Audio Intelligence:** OpenAI Whisper (Local execution via Python).
* **Context Engine:** GPT-4o (via OpenAI API) for keyword extraction and prompt engineering.
* **Visual Generation:** Stable Diffusion (Local/API) or DALL-E 3.

### Frontend (The Renderer)
* **Engine:** Remotion (React + Headless Chrome).
* **Language:** TypeScript.
* **Styling:** CSS-in-JS (Inline styles for maximum precision).

---

## 3. Project Architecture & Folder Structure

## 4. Visual Style Guide

* **Format:** 1080x1920 (9:16), 30 FPS.
* **Split 1 (Top 0-50%):** Dynamic Visuals.
    * Content: AI-generated illustrations or stock footage based on transcript context.
    * Behavior: Cuts or fades every 3-5 seconds depending on context changes.
* **Split 2 (Bottom 50-100%):** Talking Head.
    * Content: Raw video input.
    * Style: `object-fit: cover` to ensure full width.
* **Overlay (Center):** Glassmorphism Transcript.
    * Position: Absolute Center (Z-Index: 10).
    * Effect: `backdrop-filter: blur(12px)`.
    * Background: `rgba(255, 255, 255, 0.15)`.
    * Border: `1px solid rgba(255, 255, 255, 0.2)`.

---

## 5. Automation Workflow (The Pipeline)

**Trigger:** `python manage.py make_video --input="raw_video.mp4"`

1.  **Ingestion:** Script locates `raw_video.mp4` in `backend/media/raw/`.
2.  **Transcription (Whisper):** * Extracts audio.
    * Generates JSON transcript with precise `start` and `end` timestamps.
3.  **Visual Mapping (LLM):**
    * Transcript chunks are sent to GPT-4.
    * GPT-4 returns a JSON list: `[{ time: 0, prompt: "Cyberpunk city" }, { time: 5, prompt: "Robot coding" }]`.
4.  **Asset Generation:**
    * Python loop calls Image Gen API for each prompt.
    * Saves images to `backend/media/assets/`.
5.  **Props Injection:**
    * Django compiles all paths and data into `public/media/render_props.json`.
6.  **Rendering:**
    * Django executes `subprocess.call(['npx', 'remotion', 'render', ...])`.

## 6. Proof of Concept (PoC) Code

### A. The "Lean" Orchestrator (`backend/automation/management/commands/make_video.py`)

import os
import json
import subprocess
from django.core.management.base import BaseCommand
from django.conf import settings
# import whisper (Assuming locally installed)

class Command(BaseCommand):
    help = 'Orchestrate the AI Video Factory'

    def add_arguments(self, parser):
        parser.add_argument('--input', type=str, required=True, help='Filename in media/raw/')

    def handle(self, *args, **options):
        filename = options['input']
        raw_path = os.path.join(settings.MEDIA_ROOT, 'raw', filename)
        
        self.stdout.write(self.style.WARNING(f"🚀 Starting Pipeline for: {filename}"))

        # 1. SIMULATE WHISPER (Mockup for PoC)
        # In production: model = whisper.load_model("base"); result = model.transcribe(raw_path)
        transcript_data = [
            {"start": 0, "end": 3, "text": "AI Automation is the future."},
            {"start": 3, "end": 6, "text": "We use Django to orchestrate everything."},
            {"start": 6, "end": 10, "text": "And Remotion renders the pixels."}
        ]
        
        # 2. SIMULATE VISUAL MAPPING (Mockup)
        # In production: Use Image Gen API here and save to media/assets/
        visuals = [
            {"start": 0, "src": "/media/assets/robot_intro.jpg"}, # Assumes file exists
            {"start": 4, "src": "/media/assets/django_logo.jpg"}
        ]

        # 3. PREPARE PROPS FOR REMOTION
        # Note: Paths must be relative to 'public/' for Remotion
        remotion_props = {
            "videoUrl": f"/media/raw/{filename}",
            "transcript": transcript_data,
            "visuals": visuals
        }

        props_path = os.path.join(settings.BASE_DIR, '../public/media/render_props.json')
        with open(props_path, 'w') as f:
            json.dump(remotion_props, f, indent=2)

        self.stdout.write(self.style.SUCCESS("✅ Metadata Generated. Starting Render Engine..."))

        # 4. EXECUTE REMOTION CLI
        # npx remotion render <CompositionID> <Output> --props=...
        output_file = os.path.join(settings.MEDIA_ROOT, 'output', f"final_{filename}")
        
        cmd = [
            "npx", "remotion", "render", "SplitScreen",
            output_file,
            f"--props={props_path}"
        ]
        
        # Blocking call (Wait for render)
        subprocess.run(cmd, cwd=os.path.join(settings.BASE_DIR, '../'))
        
        self.stdout.write(self.style.SUCCESS(f"🎉 Video Rendered: {output_file}"))


### B. The React Component (`src/compositions/SplitScreen.tsx`)

import React from 'react';
import { AbsoluteFill, Video, Img, useCurrentFrame, useVideoConfig, interpolate } from 'remotion';
// import './style.css'; // Optional Tailwind or custom CSS

interface Segment {
  start: number;
  end: number;
  text: string;
}

interface Visual {
  start: number;
  src: string;
}

interface SplitScreenProps {
  videoUrl: string;
  transcript: Segment[];
  visuals: Visual[];
}

export const SplitScreen: React.FC<SplitScreenProps> = ({ videoUrl, transcript, visuals }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const currentTime = frame / fps;

  // Logic: Find active transcript
  const activeSegment = transcript.find(
    (seg) => currentTime >= seg.start && currentTime < seg.end
  );

  // Logic: Find active visual (Last visual that started before current time)
  const activeVisual = visuals
    .filter((vis) => currentTime >= vis.start)
    .slice(-1)[0];

  return (
    <AbsoluteFill style={{ backgroundColor: '#000' }}>
      
      {/* --- SPLIT 1: TOP (Visuals) --- */}
      <div style={{ position: 'absolute', top: 0, width: '100%', height: '50%', overflow: 'hidden' }}>
        {activeVisual && (
          <Img 
            src={activeVisual.src} 
            style={{ 
              width: '100%', 
              height: '100%', 
              objectFit: 'cover',
              // Simple Zoom Effect
              transform: `scale(${interpolate(frame, [0, 100], [1, 1.1])})` 
            }} 
          />
        )}
      </div>

      {/* --- SPLIT 2: BOTTOM (Talking Head) --- */}
      <div style={{ position: 'absolute', bottom: 0, width: '100%', height: '50%', overflow: 'hidden' }}>
        <Video 
          src={videoUrl}
          style={{ width: '100%', height: '100%', objectFit: 'cover' }} 
        />
      </div>

      {/* --- LAYER 3: GLASSY TEXT OVERLAY --- */}
      {activeSegment && (
        <div style={{
          position: 'absolute',
          top: '50%',
          left: '50%',
          transform: 'translate(-50%, -50%)',
          zIndex: 10,
          width: '85%',
          padding: '40px',
          textAlign: 'center',
          
          // GLASSMORPHISM MAGIC
          backgroundColor: 'rgba(255, 255, 255, 0.15)',
          backdropFilter: 'blur(16px)',
          WebkitBackdropFilter: 'blur(16px)', // Safari support
          borderRadius: '30px',
          border: '1px solid rgba(255, 255, 255, 0.25)',
          boxShadow: '0 8px 32px 0 rgba(0, 0, 0, 0.3)',
        }}>
          <h1 style={{
            color: 'white',
            fontFamily: 'Inter, sans-serif',
            fontWeight: 800,
            fontSize: '50px',
            margin: 0,
            lineHeight: 1.2,
            textShadow: '0 2px 10px rgba(0,0,0,0.5)'
          }}>
            {activeSegment.text}
          </h1>
        </div>
      )}

    </AbsoluteFill>
  );
};
